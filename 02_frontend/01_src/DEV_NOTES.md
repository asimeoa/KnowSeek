# KnowSeek.Ai — Frontend Dev Guide

> On-premise AI knowledge platform for industrial engineering teams.

---

## Prerequisites

- Node.js v18 or higher
- npm v9 or higher

---

## Run Locally

```bash
# Step 1 — Navigate to frontend source
cd 02_frontend/01_src

# Step 2 — Install dependencies (only needed once)
npm install

# Step 3 — Start dev server
npm run dev
```

---

## Open in Browser

After running `npm run dev`, the terminal will show:

```
VITE v5.4.21  ready in ~200ms

➜  Local:    http://localhost:8080/
➜  Network:  http://192.168.178.23:8080/
```

> ⚠️ The port may vary — always check the terminal output.
> Use the **Local** URL shown in your terminal.

---

## Stop the Server

```
Ctrl + C
```
